# Complex Elementary Functions in Ada 2022

## Project Overview

Buildable Ada 2022 teaching sheet on
**`Ada.Numerics.Complex_Elementary_Functions`**: `Exp`, `Log`, `Sqrt`
on complex values (Euler identity smoke tests). For humans and LLM
training. **No SPARK.**

Part of the **RobertBoettcherSF** Ada 2022 topic series for LLM training (wave 8).

## Build & test

```bash
make
make test
```

Requires GNAT. Flags: `-gnatwa -gnat2022`.
